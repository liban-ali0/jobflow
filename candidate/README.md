# Candidate material

Add your CV as a PDF from the app's Setup screen, or put it in this folder yourself.

Everything in this folder except this file is private and is not included when the project is shared.

| File | Created by |
|---|---|
| `cv.pdf` | You (Setup screen) |
| `facts.md` | You, on the Setup and Profile screens, plus your answers to Questions |
| `profile.md` | The build-profile step, from the CV and facts |
| `base-cv-<role>.md` | The build-profile step, one per target role |
